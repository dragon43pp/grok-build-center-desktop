Verify the download

Every file below has a sidecar published beside it, served from this site. After downloading, check the hash. On Windows: certutil -hashfile <file> SHA256. On Linux, for the .deb or AppImage, with the sidecar in the same directory: sha256sum -c <file>.sha256. On macOS: shasum -a 256 <file>. Replace <file> with the name shown on the card. A matching hash proves the download is intact and is the file that was published; it does not prove who built it.

About the unsigned warning

No release is code-signed on any platform, so the operating system will interrupt the first launch. On Windows, SmartScreen shows a prompt: choose More info, then Run anyway. On macOS, Gatekeeper blocks the app: on macOS 15 and later, open System Settings, Privacy & Security, and choose Open Anyway after a blocked attempt; on macOS 10.14 through 14, right-click the app and choose Open. Linux packages need no signature. None of this is an oversight — signing is planned but not applied for, and the SHA-256 sidecar is what makes a download checkable in the meantime.

The app checks the GitHub Releases of the project at startup and announces a new version in-app; it never installs silently. This page serves the installers themselves. ASC_DISABLE_UPDATES=1 skips that check entirely.

After you download

  • Run the installer and, if SmartScreen prompts, choose More info and then Run anyway. Launch ASC from the Start menu (type asc) and let the first CLI scan finish. Pick an agent and start a session.
  • Open the disk image and drag ASC to Applications. On first launch allow it through Gatekeeper (Open Anyway on macOS 15 and later, or right-click and Open on older versions), then let the scan finish and start a session.
  • For the AppImage, make it executable with chmod +x and run it; for the .deb, install it with apt. Launch ASC, let the first scan finish, then start a session.
