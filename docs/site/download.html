Verify before you run

Compute the SHA-256 of the file you downloaded and compare it with the value on the card. On Windows use certutil -hashfile <file> SHA256; on Linux and macOS use shasum -a 256 <file>. The sidecar .sha256 link on each card opens the published hash as a file.

These builds are unsigned

No platform vouches for these binaries: Windows SmartScreen and macOS Gatekeeper will warn on first launch, and the warnings are correct — the builds are simply not code-signed. That is why the SHA-256 is published for every asset. If you would rather build it yourself, the repository has the instructions.

There is no silent updater. When a new version is released, the changelog lists it and you download the new file yourself.

After downloading

  • Windows: run the Setup .exe and follow the prompts. It installs per user and adds a Start menu entry.
  • macOS: open the .dmg, drag the app into Applications, then right-click the app and choose Open the first time.
  • Linux: install the .deb with your package manager, or run chmod +x on the AppImage and launch it directly.

The first scan takes a few seconds and reads only local agent directories. Nothing leaves your computer until you turn on Feishu or a hosted model provider.
